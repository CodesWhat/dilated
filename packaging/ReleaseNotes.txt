Dilated 2.0.0 changes the AppleScript dictionary: commands use Dilated's own codes, and the closed display commands are now closed lid mode. Open your scripts, switch to the new command names and compile them again.
Drive Alive is now called Keep Drives Awake. Closed-lid locking is sturdier when several helpers run at once, and the Mac App Store build gets its own build number.
Closed-lid mode is still experimental. Its hardware recovery checks were not run for this release.
