# Menu bar glyphs

16x15 pt template images, 1x and @2x (pixel-doubled), black on transparent. The
app tints them for light and dark menu bars. `off` is the idle state; `on`
frames animate while the Mac is being kept awake.

- `bug-eyes/`: the brand icon. Heavy lids off, wide eyes with darting pupils on.
- `can/`: sleeping face off. `wake0`-`wake2` play once when a session starts
  (tab flips, fizz), then `on` holds with an occasional `blink`. See
  `preview.gif` for timing.
- `spiral-eyes/`: flat lines off, rotating spirals on.
- `cat-cans/`: cat in headphones, eyes open on.
